# 漫匣 MangaShelf

> 一款简洁、离线、重视隐私的 Android 本地漫画管理与阅读应用。

![漫匣封面](docs/images/app-cover.png)

漫匣用于整理保存在手机上的 ZIP / CBZ 漫画压缩包。应用可以一次导入多本漫画并安全解压，在本地书架中完成搜索、分类、合集整理、续集合并和阅读进度管理。所有漫画均保存在应用私有目录，应用不会联网，也不会上传阅读内容。

## 版本信息

- 最新正式版本与 APK：见 [GitHub Releases](https://github.com/hqzzlys/MangaShelf/releases/latest)
- Android 要求：Android 8.0（API 26）及以上
- 目标平台：Android API 37
- 应用包名：`com.localmanga.shelf`
- 技术栈：原生 Java + Android SDK

## 功能概览

### 本地漫画导入

- 通过 Android 系统文件选择器导入 ZIP、CBZ 压缩包。
- 支持一次选择并连续导入多本漫画。
- 自动扫描压缩包内的多层文件夹。
- 支持 JPG、JPEG、PNG、WEBP、GIF、BMP 图片。
- 按文件名进行自然排序，避免 `10.jpg` 排在 `2.jpg` 前面。
- 导入完成后自动生成封面并加入本地书架。

### 安全解压

- 拦截压缩包路径穿越，防止文件写出应用目录。
- 单个压缩包最多处理 10,000 个文件。
- 单个压缩包最大解压体积限制为 2 GB。
- 解压失败时不会把不完整漫画加入书架。

### 漫画书架

- 展示漫画数量、已读页数和本地占用空间。
- 支持按漫画名搜索。
- 提供全部、最近阅读、未读、收藏、读完等筛选方式。
- 支持按更新时间、漫画名称和阅读进度排序。
- 支持收藏、重命名和删除漫画；删除后先进入回收站，可恢复或永久清除。
- 自动记录最后阅读页与整体进度。

### 合集管理

![合集功能引导](docs/images/guide-collection.png)

- 创建自定义合集文件夹，用于整理同系列、同作者或同类型漫画。
- 从漫画菜单将作品加入或移出合集。
- 点击合集即可筛选其中的漫画。
- 支持重命名和删除合集。
- 删除合集只会移除分类关系，不会删除漫画文件。

### 续集合并

![续集合并引导](docs/images/guide-merge.png)

- 将新导入的续集页面追加到前作末尾，合并为一条完整漫画。
- 从续集右侧的 `⋮` 菜单选择“合并到另一漫画”，再指定前作。
- 合并前会复制并校验全部页面，发生异常时自动恢复原漫画。
- 自动阻止同一续集被重复合并到同一目标。
- 合并成功后保留原续集条目，便于核对；确认无误后可手动删除。

### 本地阅读器

- 点击屏幕两侧或左右滑动均可翻页，点击中间区域显示或隐藏阅读菜单。
- 支持双指缩放、放大后拖动画面，以及双击快速缩放。
- 自动预加载相邻页面，减少连续翻页时的等待。
- 点击页码可打开缩略图列表并快速跳转。
- 支持使用音量键翻页，阅读期间自动保持屏幕亮起。
- 自动保存每本漫画的阅读位置。
- 支持亮度调节、图片适应方式与屏幕旋转控制。
- 可在阅读设置中切换从左向右或从右向左翻页。
- 可按漫画分别保存分页/纵向连续阅读、翻页方向、亮度、图片适应和屏幕方向。
- 支持纵向连续阅读和自动裁去纯白页边；原有点击与左右滑动翻页保持可用。
- 支持为当前页添加书签，并从阅读设置中的书签列表快速跳转。

### 应用密码

- 可在书架右上角菜单设置、修改或关闭启动密码。
- 启用后，每次重新打开应用都需要先验证密码。
- 密码使用 PBKDF2 派生后保存，不在本地存储明文密码。

### 书架备份与恢复

- 将漫画图片、标题、合集、收藏、阅读进度和页书签导出为一个完整备份文件。
- 从备份恢复时新增漫画，不覆盖当前书架中的内容。
- 备份不包含应用密码，也不经过加密，应保存到安全位置。

### 首次使用引导

首次启动会展示五页橙白风格功能说明，分别介绍批量导入、本地阅读、密码保护、合集整理和续集合并。完成引导后可以直接选择第一批漫画。

## 安装

1. 在 [最新 Release](https://github.com/hqzzlys/MangaShelf/releases/latest) 下载 APK。
2. 在 Android 手机上打开 APK。
3. 若系统提示，请允许当前文件管理器或浏览器“安装未知应用”。
4. 安装后启动“漫匣”，按首次引导导入漫画。

`v1.0.1` 及后续版本使用同一签名，可以直接覆盖更新。`v1.0.0` 使用旧签名，不能覆盖安装；请先备份原始漫画压缩包，再卸载旧版。卸载会删除应用私有目录中的漫画和阅读记录。

## 使用方法

### 导入漫画

1. 点击书架右下角的橙色 `+`。
2. 在系统文件选择器中长按或使用“多选”。
3. 选择一个或多个 ZIP / CBZ 文件。
4. 等待导入完成，漫画会自动出现在书架中。

### 建立合集

1. 在“我的合集”右侧点击“新建 +”。
2. 输入合集名称。
3. 点击漫画右侧 `⋮`，选择合集操作并加入目标合集。
4. 点击合集卡片即可只查看该合集内容。

### 合并续集

1. 先确保前作和续集都已导入书架。
2. 点击续集右侧 `⋮`。
3. 选择“合并到另一漫画”。
4. 在列表中选择前作并确认顺序。
5. 合并完成后打开前作检查页面，再决定是否删除原续集。

### 备份与恢复书架

1. 打开书架右上角菜单，选择“书架备份与恢复”。
2. 选择“导出完整书架备份”，再指定保存位置。
3. 恢复时选择“从备份恢复书架”，并选中此前导出的 ZIP 文件。

恢复会把备份中的漫画新增到当前书架。重复恢复同一文件会产生副本。备份包含漫画图片、阅读记录和页书签，但未加密，不要公开分享。

### 恢复已删除的漫画

1. 点击书架右上角菜单，选择“回收站”。
2. 选择漫画并点击“恢复到书架”。
3. 只有确认不再需要时才选择“永久删除”或“清空回收站”；这些操作无法撤销。

## 隐私与数据

- 不申请传统的全盘存储权限，文件选择由 Android 系统选择器完成。
- 不包含网络权限，不请求账号，不收集遥测数据。
- 不会将漫画、文件名、密码或阅读记录发送到外部服务器。
- 导入后的内容、封面和阅读记录保存在应用私有目录中。
- 卸载应用会删除这些私有数据；重要漫画请保留原始压缩包。

## 从源码构建

### 环境要求

- JDK 17
- Android SDK 37
- Android Build Tools 35.x
- Gradle Wrapper（仓库已包含，无需单独安装 Gradle）

### Android Studio

1. 克隆仓库。
2. 使用 Android Studio 打开仓库根目录。
3. 等待 Gradle 同步完成。
4. 选择 `Build > Build APK(s)`。

### 命令行验证

Windows：

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

macOS / Linux：

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Debug APK 会生成在 `app/build/outputs/apk/debug/`。每个拉取请求也会运行相同质量检查，并把 Debug APK 上传为 GitHub Actions 构建产物。

项目无第三方运行时依赖，核心界面、导入、解压、书架和阅读器均使用 Android 原生 API 实现。

## 项目结构

```text
app/src/main/
├── java/com/localmanga/shelf/
│   ├── MainActivity.java       # 书架与漫画管理入口
│   ├── ReaderActivity.java     # 漫画阅读器
│   ├── LibraryTaskController.java # 可跨旋转保留的后台任务
│   ├── ComicRepository.java    # 漫画存储与元数据入口
│   ├── ArchiveExtractor.java   # ZIP / CBZ 安全解包
│   ├── ArchiveLimits.java      # 解包资源限制
│   ├── MergeTransaction.java   # 合并崩溃恢复事务
│   ├── NaturalPageSorter.java  # 漫画页自然排序
│   ├── AppLock.java            # 应用密码
│   ├── LibraryView.java        # 书架界面
│   └── OnboardingView.java     # 首次启动引导
└── res/                        # 主题、图标和引导图片
```
